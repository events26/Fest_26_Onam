Setup guide for the host
Teams buzz in from their own phones.
You need one laptop and about 15 minutes.
Only your laptop needs anything installed. Everyone playing just opens a web page on their phone — nothing to download, no app, no accounts. Work through “Before the day” once, in advance, so nothing is a surprise on the day itself.

Before the day Get it working once, in advance

1

Download the code

Open this page in your browser:

https://github.com/events26/Fest_26_Onam

Click the green Code button near the top right, then Download ZIP. You do not need a GitHub account or any other program.

2

Unzip it

Find the downloaded file (usually in Downloads), right-click it and choose Extract All…, then Extract. You now have a folder called Fest_26_Onam-main. Keep it somewhere easy, like your Desktop.

3

Install Python

Go to python.org/downloads and click the big yellow Download Python button. Run the file it downloads.

This is the one step people get wrong. On the first screen of the installer, tick the box at the bottom that says “Add python.exe to PATH” before clicking Install Now. If you miss it, nothing later will work, and the error message will not tell you why. If you are unsure, run the installer again and check.
4

Test it

Open the folder from step 2 and double-click start-quiz.bat. A black window should open showing three web addresses.

If it says Python is not installed, go back to step 3 — the PATH box was almost certainly missed. Close the window and try again after reinstalling.

Leave that black window open and go to step 5 to confirm it really works. Closing the window stops the quiz.

5

Allow it through the firewall

Windows will pop up a box asking whether to allow Python to communicate on the network. Click Allow access, and make sure Private networks is ticked.

If you click Cancel, phones will not be able to connect and there will be no other clue what went wrong. If you have already dismissed it, see the troubleshooting table on the next page.
6

Check it from a phone

In the black window, find the line starting Teams join. It shows an address like http://192.168.1.42:8000/ — the numbers will be different on your laptop, so use whatever your window shows.

Put one phone on the same Wi-Fi as the laptop and type that address into its browser. If the team page loads, you are ready. If not, see troubleshooting.

On the day Running the quiz

7

Get everyone on one network

The laptop and every phone must be on the same Wi-Fi. A hotspot from your own phone is the most reliable choice.

Avoid office, hotel and guest Wi-Fi. These usually stop devices from talking to each other, so phones will never reach the laptop no matter what you do. A personal hotspot avoids the problem completely.
8

Start the quiz

Double-click start-quiz.bat again. Note the Teams join address — you will read this out to everyone.

9

Put the big screen up

On the laptop, open http://localhost:8000/display in your browser and connect the projector. Then:

  • Click Full screen
  • Click Turn on sound — browsers block sound until you click once, so this must be done before the first question
10

Open your own controls

On your phone, open the same address as the teams but with /admin on the end — for example http://192.168.1.42:8000/admin — then sign in.

Ask Sanjay for the username and password before the day. There is no separate quiz password: it is the same login as the main Onam admin page, so you cannot get in without it.
Signing in needs internet, so do it early. Once you are in you stay in, even if the connection drops or the laptop restarts. Keep this page on your own phone — it shows the answers, so do not put it on the projector.
11

Set up the teams

On the admin page, open Teams & codes. Change the team names if you need to, then tap Generate codes and Save teams & codes.

Read each code out to one person per team. That phone holds the buzzer for the whole quiz.

12

Let the teams in

Read out the Teams join address. Each team opens it, picks their team name and types their code.

Watch the projector: each team's NOT JOINED label disappears as they sign in, so you can see who is still missing without asking.

13

Run each question

Read the question aloud from your phone, then:

  • Arm buzzers — every phone lights up and starts pulsing
  • The first team to tap wins; everyone else locks out instantly and the big screen fills with the winning team's colour
  • Correct gives them 10 points, or Wrong — pass it on locks them out and reopens the buzzers for everyone else
  • Show the answer on screen highlights the right option on the projector
  • Next question

Reset this question starts a question over completely, for when one has to be thrown out.

If something goes wrong

What you seeWhat to do
The black window says Python is not installed The Add python.exe to PATH box was missed during installation. Reinstall Python from python.org/downloads and tick it this time.
Phones cannot open the page, but the laptop can Almost always the firewall. Right-click the Start button, choose Terminal (Admin), and paste this in, then press Enter: New-NetFirewallRule -DisplayName "Onam Quiz" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private,Public If that does not fix it, the Wi-Fi is separating devices — switch to a phone hotspot.
Nothing opens, even on the laptop The black window is not running, or was closed. Double-click start-quiz.bat again and leave the window open.
The address does not work on phones Check you typed the numbers from your window, including :8000 at the end. Also check the phone is on Wi-Fi and has not quietly switched to mobile data.
Cannot sign in to the admin page Signing in needs a working internet connection. Check you can load any website on that phone, then try again.
A team's phone died or was locked out They sign in again with the same code — the newest phone takes over the buzzer. You can also tap Sign out next to their name on the admin page.
The laptop restarted mid-quiz Nothing is lost. Team names, codes, scores and your sign-in are all saved. Start start-quiz.bat again; teams re-open the join page.
No sound from the projector Turn on sound was not clicked on the display page. Move the mouse to make the buttons appear, then click it.
Worth a five-minute rehearsal. Run steps 8 to 13 with two phones the day before. Everything that goes wrong on the day goes wrong in the first two minutes, and it is much easier to fix when there is not a room full of people waiting.
