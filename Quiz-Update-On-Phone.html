Updating the quiz
on your phone

For the phone running the quiz
Four lines, about a minute.
Nothing gets reinstalled.
You do not reinstall anything. Termux, Python and git all stay exactly as they are — they were set up once and that still holds. Updating is four lines typed into the same black Termux screen you used before.
Your teams, codes and scores are safe. They live in a separate file that updates never touch, so you can do this mid-event if you have to.

Open Termux

Everything below is typed into the Termux app — the black screen with a prompt. Not a browser, not a file manager. If the quiz is still running you will see it printing away in there.

Press Enter after every line you type.

1

Stop the quiz that is running

Your phone keyboard has no Ctrl key, so there are two ways to send Ctrl-C:

Easiest
Hold Volume Down and tap C
Volume Down acts as the Ctrl key in Termux.
Or
Swipe up on the keyboard, tap CTRL then C
Swiping up reveals Termux's extra key row.

It worked when the printing stops and you get a prompt back — a line ending in a $, waiting for you to type.

Do not skip this. If the old quiz is still running, the update looks like it did nothing — because the running copy is still the old one, sitting in memory.
2

Go to the quiz folder

cd ~/Fest_26_Onam

The ~ means “my home folder”, so this works no matter where you were.

3

Download the update

git pull

It prints a few lines listing what changed. If it says “Already up to date.” you already have the newest version and there was nothing to fetch.

This step needs internet — running the quiz does not, but fetching an update does. Do it while you still have wifi or mobile data, not once you are on a hotspot with nothing behind it.
4

Start it again

termux-wake-lock python quiz-server.py

Check the hotspot is still on. It prints the addresses again and you are back exactly where you were.

termux-wake-lock is not optional. Without it Android suspends the quiz when the screen sleeps, and every phone in the room stops responding with nothing on screen to explain why.

Do you need git on the phone?

Yes — and it is already there. It was installed alongside Python during the original setup, which is how the quiz got onto the phone in the first place. You can check with:

git --version

If it ever says “command not found”, install it with pkg install -y git and carry on.

If step 3 goes wrong

What it saysWhat to do
“git: command not found” Git is missing. Run pkg install -y git, then try git pull again.
“Your local changes would be overwritten” Something in the folder was edited by hand. To discard those edits and take the published version: git fetch origin git reset --hard origin/main Your teams, codes and scores still survive this.
“could not resolve host”, or any network error The phone has no internet. Connect to wifi or mobile data and try again. The quiz itself does not need a connection — only the update does.
“not a git repository” You are in the wrong folder. Run cd ~/Fest_26_Onam and try again. If that says no such file, type ls to list what is actually there and look for the folder name you cloned.
Termux was closed by accident Nothing is lost. Reopen it and run the three lines from steps 2 and 4: cd ~/Fest_26_Onam, termux-wake-lock, python quiz-server.py.
Do this the day before, not on the day. An update needs a connection and a minute of calm. Once it is done and the quiz has started again, you can go back to a hotspot with no internet and everything keeps working.
