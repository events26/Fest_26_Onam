Onotsavam Quiz Buzzer
Which address each person opens,
and where the numbers come from.
There is no fixed web address for this. The device running the quiz works out its own address when it starts, and prints it. That address is different on every machine and every network, so always read it off the screen rather than copying one from anywhere else — including this page.

Where to find the address

Two places, and they always agree:

1

On the device running the quiz

The window that started it prints a line beginning Teams join. That is the one to read out.

2

On the projector

Before the quiz starts, the big screen shows the same address in large type under “Grab a phone, join the buzzer”. Easiest option — teams can simply read it off the wall instead of being told.

http://192.168.43.1:8000/
192.168.43.1changes on every host
:8000always this, do not miss it
The :8000 is not optional. Leaving it off is the single most common typing mistake, and the page simply will not load. There is no error explaining why.
Examples of what it might look like. On an Android phone hotspot it is usually 192.168.43.1. On a laptop on home wifi, something like 192.168.1.6. On an iPhone hotspot, 172.20.10.x. All are normal — use whichever your own screen shows.

If the quiz runs on a phone, the quizmaster can open the controls on that same phone using http://127.0.0.1:8000/admin. 127.0.0.1 means “this device”, so it works even with no signal at all.

Getting the teams connected

1

Everyone joins the same hotspot

Every phone, and the laptop driving the projector, must be on the same network as the device running the quiz.

Office, hotel and guest wifi will not work. These stop devices talking to each other, so phones can never reach the quiz no matter what is typed. A personal hotspot avoids the problem completely.
2

Open the address in a browser

Type it into Chrome or Safari as it appears on the projector. It is a normal web page — there is no app to install and no account to create.

3

Pick the team, enter the code

Each team taps their own name and types the code the quizmaster read out. The screen then shows a large pookkalam — that is the buzzer.

One phone per team. If a second phone signs in with the same code it takes over, and the first is told it has been signed out. That is deliberate: a flat battery cannot lock a team out for the rest of the quiz.
4

Check nobody is missing

The projector's scoreboard marks every team that has not signed in yet with NOT JOINED. When those labels have all gone, everyone is in and you can start.

If someone cannot connect

CheckWhat to do
Did they include :8000? By far the most common cause. The address will not work without it.
Are they on the right network? Phones often drop back to mobile data when a hotspot has no internet. Check the wifi name on the phone matches the one the quiz is running on.
Did the address change? If the hotspot was switched on after the quiz started, the address may have moved. The projector corrects itself within about fifteen seconds — read it again from the big screen.
Does it work on the host device? On the device running the quiz, open http://localhost:8000/. If that fails, the quiz is not running — restart it. If it works but phones cannot connect, it is the network, not the address.
Is a firewall in the way? On a laptop host, Windows must have been allowed through the firewall when it asked. If that was refused, phones cannot connect and it cannot be fixed without an administrator — run the quiz from a phone instead.
Have one phone connect before the room fills up. If a single phone can load the page, every phone can. Finding out otherwise in front of everyone is the one thing worth avoiding.
